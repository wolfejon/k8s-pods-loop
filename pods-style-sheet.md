# Pods loop — style sheet (locked off X north star)

Steal vibe, not frames/IP. No anime character, no JP glyphs, no AGI/Sydney labels, no X chrome.

## Palette
| Token | Hex | Use |
|---|---|---|
| paper | `#E5DECE` | canvas / field |
| navy | `#16234E` | ink shapes, shelf, host |
| plum | `#5E286D` | secondary ink / shadow |

## Type
- Hero lyric: oversized condensed bold sans caps, pink or navy on paper
- Chorus pinned bottom every frame — largest readable element
- No second panel of UI chrome

## Motion
- Cut-paper / screenprint shapes, 1 hard shadow max, constant subtle grain
- Hard cuts + stepped snaps synced to mute / bitcrush / cork-pop (~128 BPM)
- Solid geometry > particles; no soft fades between beats

## Beats (unchanged timing)
0.5–4 fill/exit · 4–8 respawn ID · 8–12 node snap-back · chorus under all
